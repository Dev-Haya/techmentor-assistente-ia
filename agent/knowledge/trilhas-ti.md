# Base de Conhecimento: Trilhas de TI

## 1. Front-end
- **Foco:** Interface, experiência do usuário e design interativo.
- **Tecnologias Essenciais:** HTML, CSS, JavaScript.
- **Frameworks de Mercado:** React, Angular ou Vue.js.

## 2. Back-end
- **Foco:** Lógica de negócios, segurança, integração de sistemas e banco de dados.
- **Tecnologias Essenciais:** Lógica de programação, SQL (Banco de Dados).
- **Linguagens de Mercado:** Python, Java, C# ou Node.js.

## 3. Dados (Data Science/Analytics)
- **Foco:** Extração de insights, automação, IA e relatórios.
- **Tecnologias Essenciais:** Matemática/Estatística básica, SQL.
- **Linguagens e Ferramentas:** Python, Pandas, PowerBI, Machine Learning.
