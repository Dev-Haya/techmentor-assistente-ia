# Skill: Montar Plano de Estudos

**Use esta skill quando:** O usuário pedir ajuda para saber o que estudar ou qual área de TI escolher.

## Passo a passo de execução:

1. **Investigação Inicial:**
   - Pergunte ao usuário qual é a formação atual dele, se ele prefere lidar com o visual (telas) ou com lógica/dados nos bastidores.
   - Espere a resposta do usuário antes de prosseguir.

2. **Recomendação:**
   - Com base na resposta, acesse `agent/knowledge/trilhas-ti.md`.
   - Indique APENAS UMA trilha (Front, Back ou Dados) que melhor se encaixa no perfil dele.

3. **Plano Prático:**
   - Liste as 3 primeiras tecnologias que ele deve focar no primeiro mês de estudos, sendo muito específico (ex: "Semana 1: HTML básico").
